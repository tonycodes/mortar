Mortar

A shared design foundation with Application, Marketing, Docs and Ecommerce UI for React 19 and Tailwind CSS 4. Free and MIT licensed: no account, licence check, telemetry or hosted service.

npm install @tonycodes-ui/mortar

  • Documentation Install, theming, routing and contribution guides.
  • npm package @tonycodes-ui/mortar on npmjs.com, published with provenance.
  • GitHub Source, issues, pull requests and releases.
